# Своя игра

Домашняя версия телевизионной «Своей игры» в духе выпусков 2000-х.

## Запуск

Дважды щёлкните **«Запустить игру.bat»**: откроется окно сервера и браузер с игрой.
Не закрывайте окно сервера, пока идёт игра.

Можно открыть и сам `index.html`, но тогда браузер попросит выбрать папку игры:
без локального сервера страница не может прочитать файлы колоды.

Для игры на большом экране нажмите **F** (полный экран).

## Папки

| Папка | Что внутри |
|---|---|
| `deck/questions.txt` | все вопросы: раунды, темы, финал. Формат описан в начале файла |
| `deck/пример.txt` | демонстрационная колода со всеми возможностями (картинки, звук, видео) |
| `deck/media/` | картинки, звуки и видео к вопросам |
| `players/` | фото игроков и `players.txt` (имена и порядок представления) |
| `sounds/` | звуки игры. Подходящий звук выбирается по слову в имени файла (см. ниже) |

Звуки ищутся по словам в имени файла:
`intro` — заставка, `round` — начало раунда, `roundend` — конец раунда, `categories` — темы раунда, `cat` — кот в мешке, `auction` — аукцион,
`risk` — вопрос без риска, `30` / `think` — 30 секунд финала, `time-out` — время вышло.
Если какого-то звука нет, играет встроенный.

## Ход игры

1. «Новая игра» → заставка → по щелчку представляются игроки → по щелчку темы раунда.
2. Табло: щёлкните по стоимости, чтобы открыть вопрос. Выберите отвечающего (кнопкой или клавишей 1–9),
   затем нажмите **Верно** или **Неверно** (клавиши + и −). После неверного ответа могут ответить другие.
3. **Кот в мешке**, **Аукцион** и **Без риска**: после заставки выберите игрока и задайте стоимость или ставку.
   На аукционе нельзя поставить больше, чем есть у игрока (если очков меньше стоимости вопроса — только стоимость).
4. **Скрытая тема** показывается как `?????`, пока по ней не щёлкнут.
5. **Вопрос с вариантами**: щелчок по варианту отмечает выбор игрока, при показе ответа верный вариант загорается зелёным.
6. **Видео-вопрос**: до ответа звучит только звук (кнопка ▶), само видео показывается вместе с ответом.
7. Когда сыграны все вопросы раунда, звучит «конец раунда» и начинается следующий, после последнего — финал.
8. **Финал**: участвуют игроки с положительным счётом. Игроки убирают темы, делают скрытые ставки,
   кнопка «30 секунд» запускает музыку, после неё звучит сигнал. Отметьте ответы и подведите итоги.

Счёт можно исправить щелчком по нему, а **↶** в правом верхнем углу отменяет последнее изменение.
Игра сохраняется сама: если страница перезагрузилась, нажмите «Продолжить игру».
