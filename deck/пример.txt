#  СВОЯ ИГРА — файл вопросов (тестовая колода)
# ═══════════════════════════════════════════════════════════════════
#  Строки, начинающиеся с #, — комментарии, игра их не читает.
#
#  НАЗВАНИЕ: ...        — название игры (показывается на заставке)
#  РАУНД: Название      — начало нового раунда
#  ТЕМА: Название       — новая тема в текущем раунде
#  ФИНАЛ: Название      — финальный раунд (название можно не писать)
#
#  Вопрос — одна строка:   стоимость | текст вопроса | ответ
#    Стоимость можно не писать — тогда 100, 200, 300… (во 2-м раунде 200, 400…)
#    В финале у каждой темы один вопрос:   текст вопроса | ответ
#    Чтобы перенести строку внутри вопроса, напишите \n
#
#  Теги в квадратных скобках — в любом месте строки вопроса:
#    [кот в мешке]                 — Кот в мешке (можно просто [кот])
#    [кот в мешке: Тема кота]      — Кот в мешке со своей темой
#    [аукцион]                     — Вопрос-аукцион
#    [без риска]                   — Вопрос без риска (×2, без штрафа)
#    [картинка: media/файл.jpg]    — картинка к вопросу
#    [аудио: media/файл.mp3]       — звук к вопросу (кнопка ▶ / ❚❚)
#    [видео: media/файл.mp4]       — видео к вопросу
#    [ответ-картинка: media/x.jpg] — картинка, показываемая вместе с ответом
#    [ответ-аудио: media/x.mp3]    — звук, доступный вместе с ответом
#    [комментарий: текст]          — пояснение, показывается под ответом
#  Пути к файлам указываются относительно папки deck.
# ═══════════════════════════════════════════════════════════════════
